BookNook is an online library management platform where users can explore books, borrow books, and manage their personal book collections. The platform provides an easy-to-use interface for readers and book contributors.

Features are:
1. User Authentication: Register and log in using email and password or Google authentication.
2. Browse Books: Explore all available books and discover new arrivals.
3. Add Books: Logged-in users can add new books with details, descriptions, and images.
4. My Books: Users can view, edit, and delete the books they have added.
5. Book Borrowing: Borrow available books through a simple borrowing process.
6. My Borrows: View borrowed books and return them when finished.

There are also copy management,borrow duplication prevent,dark-light mode and responsive design.

Technologies Used are- Next.js,Typescript,Tailwind CSS,shadcn/ui,Framer motion,Swiper.js,
Betterauth,Node.js,Express.js,MongoDB.
